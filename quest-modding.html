Rooting the Meta Quest 1, 2, 3, and 3S

A simple guide for using Singularity to get temporary root access on supported Meta Quest system versions.

Supported versions: v2.1-v2.7 · Updated September 22, 2026
Singularity: https://github.com/Lumince/singularity/releases FreeXR Discord: https://discord.gg/ABCXxDyqrH

⚠️ IMPORTANT WARNING

Do not continue if your headset is running a system version outside v2.1-v2.7. The app will just say it is unsupported.

The Quest 3S XBOX Edition is currently having issues with this root method, so it may fail more often or not work correctly on some Quest 3S headsets.

Check the FreeXR Discord for the latest compatibility information and fixes before attempting it on a Quest 3S.

Requirements

  • A Meta Quest 1, Quest 2, Quest 3, or Quest 3S
  • Your headset must be running system version v2.1-v2.7
  • Developer Mode and ADB access must be enabled
  • Automatic updates should be disabled so your headset does not update to an unsupported version

Instructions

  1. Open the Singularity GitHub release page linked at the top of this page.
  2. Download the APK from the release files.
  3. Install or sideload the APK onto your Quest headset.
  4. Open the app and carefully follow the instructions shown on-screen.
  5. The process may fail several times before working. Restart the app and try again when necessary.
It took me around eight attempts before it successfully worked.
VERSION SUPPORTED: Most versions between v2.1 and v2.7 (as of September 22, 2026).

Important Root Information

P.S: This is only temporary root.

You can enable root on boot, though, which makes it feel almost seamless because root can automatically come back after restarting the headset.

The other Quest root methods currently available are also temporary, so there is not currently a better permanent-root option.
